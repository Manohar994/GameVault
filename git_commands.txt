git init
Initializes a new Git repository in the current folder.

git branch -M main
Renames the current branch to main.

git add <file>
Stages the selected file so it can be included in the next commit.

git commit -m "message"
Creates a commit containing the staged changes and a descriptive message.

git branch feature
Creates a new branch named feature.

git switch feature
Switches the working directory to the feature branch.

git switch main
Switches the working directory back to the main branch.



git log --oneline --graph --decorate --all
Displays a compact commit history with branch and merge relationships.

git status --short
Shows a concise summary of modified, staged, and untracked files.

git check-ignore <file>
Checks whether a file or folder is ignored by Git and identifies the matching rule.

git revert --no-edit HEAD
Creates a new commit that reverses the changes introduced by the latest commit.

git remote add origin <URL>
Connects the local repository to the remote GitHub repository named origin.

git remote -v
Displays the URLs configured for the remote repositories.

git push -u origin main
Pushes the main branch to GitHub and sets its upstream tracking branch.

git push -u origin feature
Pushes the feature branch to GitHub and sets its upstream tracking branch.


git fetch origin
Downloads the latest branch and commit information from the remote repository without changing the working files.

git ls-remote --heads origin
Lists the branches currently available on the remote GitHub repository and their commit hashes.

git status -sb
Displays the current branch, upstream tracking status, and a short summary of working-tree changes.

git branch -a
Lists local branches and remote-tracking branches.

git diff --name-status main origin/main
Shows which files differ between the local main branch and the remote main branch.

git rev-list --left-right --count main...origin/main
Compares the number of commits that exist only on the local branch and only on the remote branch.

git merge-base --is-ancestor origin/main main
Checks whether the remote main history is already included in the local main branch.

git merge --no-ff feature -m "Merge feature branch into main"
Merges the feature branch into main and creates a separate merge commit.

git merge --allow-unrelated-histories -s ours origin/main -m "Merge existing GitHub history"
Connects the previously unrelated GitHub main history to the local main history while retaining the local project files.

git merge --allow-unrelated-histories -s ours origin/feature -m "Merge existing GitHub feature history"
Connects the previously unrelated remote feature history to the local feature history while retaining the local feature files.

git show --stat <commit>
Displays a commit's details and a summary of the files changed by that commit.
